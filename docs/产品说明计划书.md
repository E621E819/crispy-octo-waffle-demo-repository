# Exam Radar 产品说明计划书

## 1. 产品概述

Exam Radar 是面向大学课程学习者的考试智能复习工作区。它把教学大纲、讲义、教程、作业、历年试卷和个人答题记录连接起来，帮助用户回答三个问题：课程在考什么、应该先复习什么、下一道题应该练什么。

## 2. 用户痛点与目标用户

留学生和需要使用英文课程资料的大学生，通常需要在多个 PDF、课件和历年试卷之间反复切换，难以判断知识点的重要性，也难以把错题转化为下一步练习。Exam Radar 面向这类学生，提供带来源依据的课程理解、考试模式分析和个性化练习。

## 3. 核心创新

- 先建立 Course Knowledge Map，再生成复习资料，避免直接输出脱离课程上下文的总结。
- 将历年题拆解为 Question DNA，记录概念、题型、认知层级、分值、年份和推理技能。
- 用可解释的 Exam Priority Score 综合频率、分值、近期性、教学计划、题型多样性和个人薄弱点。
- 通过 Generator → Critic → Verifier 检查变式题是否改变情境、数据或措辞，同时保留原推理结构。
- 依据答题反馈更新知识点掌握度，并推荐下一道更值得练习的题。

## 4. 三类核心能力

### Course Intelligence

支持 PDF、DOCX、PPTX、TXT 和 Markdown 资料上传。用户点击 Analyze course 后，系统提取可引用的文本和页码标记，生成课程知识点、章节关系和来源引用。

### Exam Intelligence

系统从被标记为历年试卷的资料中提取 Question DNA，计算题型分布和 Exam Priority Score。分数是透明的加权学习指导，不是逻辑回归模型，也不保证预测未来考题。

### Adaptive Practice

用户可以从高优先级或薄弱知识点生成练习题。题目公开题干和变式检查，提交答案后才显示评分、参考答案、引用反馈和掌握度变化。

## 5. Knowledge Map 与 Revision Pack

Knowledge Map 将章节、课程目标、知识点和历年题关联起来。用户可以勾选章节，生成 Notes、Formula Sheet 或 Flashcards，并在线编辑后导出 Markdown、DOCX 或 PDF。

## 6. 技术架构

前端采用 Vue 3、TypeScript 和 Vite；后端采用 FastAPI、LangGraph 和 OpenAI Responses API；本地开发使用 SQLite，线上可使用 Vercel Blob 保存共享状态。AI 请求只在服务端执行，资料文本被放入明确的非可信数据区域，返回的 sourceId 会经过校验。

## 7. 登录、隐私与安全

系统支持评审登录，并提供知乎 OAuth Authorization Code 流程的服务端实现。OAuth 使用 state 校验、回调地址白名单、HttpOnly/Secure/SameSite 会话 Cookie，访问令牌不返回浏览器。登录统计只记录成功登录的唯一用户和必要的时间、来源信息，用于项目体验及比赛人气统计，不收集不必要的个人资料。

## 8. Demo 操作流程

1. 登录后进入 Machine Learning 示例课程。
2. 查看 Exam Radar 和 Knowledge Map，点击 KNN 或 Logistic Regression 查看优先级构成。
3. 打开 Exam DNA，查看题型、年份和认知层级分布。
4. 对薄弱知识点生成变式题并提交答案。
5. 查看评分、引用反馈和掌握度变化。
6. 勾选章节生成 Revision Pack，编辑后导出 DOCX、PDF 或 Markdown。
7. 创建只读课程分享链接并发表评论，确认个人答题和掌握度不会被分享。

## 9. 提交访问信息

- 公网 Demo：部署完成并通过 Smoke Test 后填写真实 HTTPS 地址。
- 健康检查：公网地址加 `/api/health`。
- 评审账号和密码：见仓库根目录 `SUBMISSION_ACCESS.md` 的部署后安全填写内容。
- 知乎 OAuth：需要在部署平台配置正式知乎应用凭据和完全匹配的 HTTPS 回调地址。

## 10. 已知限制与后续计划

当前示例课程使用 authored demo 数据，不是真实大学试卷。扫描 PDF、图片公式和手写内容需要外部 OCR；DOCX 原始分页不可用；线上持久化和并发能力取决于部署平台配置。后续计划包括更完整的 OIDC/RBAC、异步解析队列、向量检索、教师模式和实时协作。
